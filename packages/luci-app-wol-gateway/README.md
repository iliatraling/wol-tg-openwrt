# luci-app-wol-gateway

Отдельный LuCI-пакет для управления пакетом `wol-gateway`.

Возможности: статус службы и автозапуска, запуск/остановка/перезапуск, редактирование всех восьми переменных ENV, проверка конфигурации, тест Telegram API, просмотр последних 30 записей системного журнала и переключатель подробного логирования.

Токен не возвращается из RPC и не отображается в интерфейсе. Пустое поле токена сохраняет прежнее значение. ENV остаётся root:root с правами 600. Конфигурация проверяется тем же валидатором, что используется основным процессом, и заменяется атомарно.

Пакет не зависит от `wol-gateway` и удаляется независимо. Для фактического управления основной пакет должен быть установлен.

Журнал идёт в штатный `logd`: кольцевой буфер находится в RAM, отдельный файл не создаётся. При выключении подробного логирования INFO-сообщения подавляются, ERROR продолжают записываться.
